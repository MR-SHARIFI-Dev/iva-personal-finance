## 🇮🇷 قابلیت‌های کامل آیوا

IVA یک پلتفرم حسابداری شخصی همه‌کاره است. در ادامه تمام قابلیت‌های آن را بررسی می‌کنیم:

---

### 📊 ۱. داشبورد (نمای کلی)

صفحه اصلی IVA یک **داشبورد حرفه‌ای** شامل:

| بخش | توضیح |
|-----|-------|
| **کارت سلام** | دارایی خالص با انیمیشن شمارنده + مقایسه با ماه قبل |
| **سه KPI** | درآمد، هزینه و پس‌انداز ماه جاری با اسپارک‌لاین |
| **نمودار جریان نقدی** | نمودار میله‌ای ۶ ماهه درآمد/هزینه |
| **دونات هزینه‌ها** | سهم دسته‌های هزینه از کل مصارف ماه |
| **تحلیل‌های هوشمند** | هشدار بودجه، نرخ پس‌انداز، پیش‌بینی هدف |
| **تراکنش‌های اخیر** | ۵ تراکنش آخر با قابلیت ویرایش |
| **بودجه‌ای پرمصرف** | ۳ بودجه ب اترین درصدمصرف |
| **نزدیک‌ترین هدف** | حلقه پیشرفت نزدیک‌ترین هدف به تحقق |

---

### 💳 ۲. تراکنش‌ها

مدیریت کامل تراکنش‌های مالی:

- **ثبت تراکنش جدید**: عنوان، مبلغ، نوع (درآمد/هزینه)، دسته، حساب، تاریخ، یادداشت
- **ویرایش و حذف**: با قابلیت برگردان (Undo) یک‌کلیکی
- **جستجوی زنده**: با پشتیبانی از اعداد فارسی
- **فیلتر**: نوع، دسته، حساب، ماه
- **مرتب‌سازی**: تاریخ (نزولی/صعودی)، مبلغ (بزرگ/کوچک)
- **بیشتر**: دکمه «نمایش بیشتر» برای صفحه‌بندی
- **خروجی CSV**: با فرمت استاندارد و BOM برای اکسل

---

### 🏦 ۳. حساب‌ها

مدیریت حساب‌های بانکی و کیف پول:

- **انواع حساب**: بانکی، کارت، وجه نقد، پس‌انداز، کیف پول
- **موجودی خودکار**: با ثبت/حذف تراکنش، موجودی حساب‌ها همگام می‌شود
- **مجموع دارایی**: نمایش جمع کل دارایی‌ها
- **رنگ‌بندی**: انتخاب رنگ دلخواه برای هر حساب
- **حذف آبشاری**: با حذف حساب، تمام تراکنش‌های مرتبط هم حذف می‌شوند

---

### 🎯 ۴. بودجه‌بندی

کنترل هزینه‌ها با بودجه:

- **سقف دسته‌ای**: برای هر دسته هزینه یک سقف ماهانه تعیین کنید
- **درصد مصرف**: نمایش درصد مصرف نسبت به سقف
- **هشدار عبور**: اگر از سقف بگذرید، کارت بودجه قرمز می‌شود
- **یکتا بودن دسته**: هر دسته فقط یک بودجه می‌تواند داشته باشد

---

### 🎯 ۵. اهداف مالی

برنامه‌ریزی برای رویاها:

- **تعریف هدف**: نام، مبلغ هدف، مبلغ پس‌اندازشده، مهلت (اختیاری)
- **حلقه پیشرفت**: نمایش درصد تحقق هدف
- **افزودن پس‌انداز**: دکمه مخصوص برای اضافه کردن به پس‌انداز
- **پیش‌بینی رسیدن**: تخمین تعداد ماه‌های باقی‌مانده بر اساس میانگین پس‌انداز ماهانه
- **شمارش معکوس**: نمایش روزهای باقی‌مانده تا مهلت

---

### 🔄 ۶. بدهی و طلب

پیگیری تعهدات مالی:

- **بدهی**: مبالغی که شما بدهکار هستید
- **طلب**: مبالغی که از دیگران طلب دارید
- **سررسید**: تاریخ سررسید با برچسب هوشمند (روزها باقی‌مانده / امروز / گذشته)
- **تسویه**: امکان علامت‌گذاری به عنوان تسویه‌شده

---

### 📈 ۷. گزارش‌ها

تحلیل عمیق مالی:

- **بازه‌های ۳/۶/۱۲ ماهه**: با دکمه‌های تغییر بازه
- **KPIها**: نرخ پس‌انداز، میانگین هزینه روزانه، پیش‌بینی پایان ماه
- **نمودار جریان نقدی**: میله‌ای گروهی
- **نمودار روند خالص**: خطی نرم با ناحیه
- **دسته‌های پرهزینه**: رتبه‌بندی با نوار پیشرفت
- **وضعیت بودجه‌ها**: مصرف هر بودجه در ماه جاری
- **بزرگ‌ترین هزینه**: نمایش بزرگ‌ترین هزینه در بازه

---

### ⚙️ ۸. تنظیمات

شخصی‌سازی کامل:

- **پروفایل**: تغییر نام نمایشی
- **ظاهر**: تم روشن/تاریک/سیستمی، زبان (فارسی/انگلیسی)، واحد پول (تومان/ریال)
- **داده**: خروجی JSON، ورود JSON، بازنشانی به داده نمونه
- **درباره**: نسخه، وضعیت PWA، مجوز، میان‌برهای صفحه‌کلید

## ✨ Features (English)

IVA is a full-featured personal finance platform. Here's everything it can do:

### 📊 1. Dashboard (Overview)

The main page is a **professional dashboard** with:

| Section | Description |
|---------|-------------|
| **Hero Card** | Net worth with count-up animation + month-over-month comparison |
| **Three KPIs** | Income, expense and savings with sparklines |
| **Cash Flow Chart** | 6-month grouped bar chart for income/expense |
| **Expense Donut** | Category share of monthly spending |
| **Smart Insights** | Budget alerts, savings rate, goal predictions |
| **Recent Transactions** | Last 5 transactions with inline edit |
| **Top Budgets** | Top 3 budgets by usage percentage |
| **Closest Goal** | Progress ring for the nearest goal |

### 💳 2. Transactions

Complete transaction management:

- **New transaction**: Title, amount, type (income/expense), category, account, date, note
- **Edit & delete**: With one-click Undo support
- **Live search**: Supports Persian digits
- **Filters**: Type, category, account, month
- **Sort**: Date (desc/asc), amount (largest/smallest)
- **Pagination**: "Show more" button
- **CSV export**: Standard format with BOM for Excel

### 🏦 3. Accounts

Bank account and wallet management:

- **Account types**: Bank, card, cash, savings, wallet
- **Auto-balance**: Account balances update automatically with transactions
- **Total assets**: Shows sum of all account balances
- **Color coding**: Custom color per account
- **Cascade delete**: Deleting an account removes its linked transactions

### 🎯 4. Budgeting

Control spending with budgets:

- **Per-category cap**: Set a monthly limit for each expense category
- **Usage percentage**: Shows how much of the budget has been used
- **Over-limit warning**: Budget card turns red when exceeded
- **Unique category**: Only one budget per category

### 🎯 5. Financial Goals

Plan for your dreams:

- **Define goal**: Name, target amount, saved amount, deadline (optional)
- **Progress ring**: Visual representation of goal achievement
- **Add funds**: Dedicated button to add to savings
- **ETA prediction**: Estimated months remaining based on avg monthly savings
- **Countdown**: Days remaining until deadline

### 🔄 6. Debts & Receivables

Track your financial obligations:

- **Debts**: Amounts you owe
- **Credits/receivables**: Amounts owed to you
- **Due dates**: Smart labels (days left / due today / overdue)
- **Settlement**: Mark as settled with toggle

### 📈 7. Reports

Deep financial analysis:

- **3/6/12-month ranges**: Switchable range buttons
- **KPIs**: Savings rate, avg daily spend, month-end projection
- **Cash flow chart**: Grouped bars
- **Net trend chart**: Smooth line with area fill
- **Top categories**: Ranked with progress bars
- **Budget status**: Per-budget usage in current month
- **Biggest expense**: Show largest transaction in range

### ⚙️ 8. Settings

Full customization:

- **Profile**: Change display name
- **Appearance**: Light/Dark/System theme, language (Persian/English), currency (Toman/Rial)
- **Data**: JSON export, JSON import, reset to sample data
- **About**: Version, PWA status, license, keyboard shortcuts
